# MJ 小红书发布桥

该浏览器扩展负责把 MJ 创作平台中已经确认的成品封面、项目图片、标题、正文和话题，同步到小红书官方图文创作中心。

## 安装

1. 下载并解压 `mj-xhs-draft-bridge.zip`。
2. 在 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 `mj-xhs-draft-bridge` 文件夹。
5. 刷新 MJ 小红书创作服务平台，页面显示“MJ 发布桥已连接”即安装成功。

## 每日小红书研究

打开任意小红书室内设计原笔记，在页面空白处点击鼠标右键，选择“收藏到 MJ 引流笔记库”。扩展会保存当前原笔记链接、标题与页面可见正文；回到平台点击“同步右键收藏”即可进入引流笔记库，并为后续原创内容生成提供结构参考。

## 笔记评论秘书

点击“同步最近笔记评论”后，扩展打开本人主页和最近 3 篇公开笔记，读取当前页面可见的评论并建立处理队列。点击“确认并自动回复安全评论”后，扩展最多回复 5 条，逐条限速发送。包含联系方式、投诉、退款、侵权、举报等内容的评论自动转人工。

## 安全边界

- 只接受 MJ 创作平台交付的草稿。
- 只读取该平台保存的项目图片。
- 只在小红书官方创作中心发布页预填内容。
- 研究只读取小红书公开搜索页中可见的笔记卡片，不读取私信或账号隐私数据。
- 评论功能只读取本人公开笔记中当前可见的评论，不读取私信。
- 人工模式不会点击最终“发布”按钮。
- 自动模式只接受平台中针对单篇笔记的明确确认，授权 5 分钟内有效且只能消费一次。
- 不处理或绕过登录、验证码、审核与风控。
