# MJ 小红书发布桥

该浏览器扩展只负责把 MJ 创作平台中已经人工确认的项目图片、标题、正文和话题，预填到小红书官方创作中心。

## 安装

1. 下载并解压 `mj-xhs-draft-bridge.zip`。
2. 在 Chrome 打开 `chrome://extensions/`，或在 Edge 打开 `edge://extensions/`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的 `mj-xhs-draft-bridge` 文件夹。
5. 刷新 MJ 小红书创作服务平台，页面显示“MJ 发布桥已连接”即安装成功。

## 安全边界

- 只接受 MJ 创作平台交付的草稿。
- 只读取该平台保存的项目图片。
- 只在小红书官方创作中心发布页预填内容。
- 不点击最终“发布”按钮。
- 不处理或绕过登录、验证码、审核与风控。
