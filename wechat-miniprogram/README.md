# 栖作微信小程序

这是网站平台的原生微信小程序版本。每个用户以微信 OpenID 建立独立工作区，不依赖 OpenAI 登录，也不会读取网站作者或其他用户的资料。

## 已实现

- 最多上传 10 张项目实景图到 CloudBase 云存储。
- 住宅、商业、办公、酒店、展陈等项目分类。
- 生成三个标题、封面标题、正文与话题标签。
- 项目资产库、人工确认、发布排期和研究参考。
- 小红书文案一键复制，保留人工确认发布。
- 服务端所有查询和修改均使用当前微信 OpenID 过滤。

## 腾讯云与微信配置

1. 在微信公众平台注册小程序并取得 AppID。
2. 在微信开发者工具导入本目录，将 `project.config.json` 的 `appid` 替换为真实 AppID。
3. 在微信开发者工具中开通云开发，选择上海地域并记录环境 ID。
4. 创建数据库集合：`studio_projects`、`studio_settings`、`studio_research`。集合权限设为“仅云函数可读写”。
5. 在云开发面板部署 `cloudfunctions/studio`，选择“云端安装依赖”。
6. 编译后分别测试两个微信账号，确认项目列表互不可见。

## 上线限制

- `touristappid` 仅用于代码导入，不能上传正式版本。
- 手机号按钮已接入微信授权事件；读取真实手机号还需在云函数中调用微信手机号接口，并满足微信平台资质要求。
- 小红书没有正式接口授权时，小程序只复制文案并引导人工发布，不会模拟点击或绕过平台限制。
- 正式发布需在微信公众平台提交隐私保护指引、服务类目、体验版和审核版本。
